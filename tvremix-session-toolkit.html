Session Scan Prompts

Run once per session. Use the extension-only full scan if TVRemix can read your chart. Use the classic prompts only when you want a more segmented workflow.

Best current workflow: If you are using the TVRemix browser extension and it can read your visible chart, start with the full extension scan below. It is not for Claude MCP.
Scan S1 · Full Session Scan (TVRemix Extension only)
1 prompt
[TVRemix Extension — screen read required. Do not use this prompt in Claude MCP.] Look at my current chart and give me a full session scan: 1. Instrument, timeframe, and current price. 2. OHLC of the last completed candle. 3. PDH and PDL — exact prices, and is price above, below, or between them? 4. 15M and 1H structure — HH/HL or LH/LL, or ranging? 5. Nearest untested level above and nearest below current price. 6. Any setup forming right now? A-grade / B-grade / Skip — one sentence why. 7. If Skip: what condition would change that to a valid entry? Numbers only. No padding.
Use this in the RemixTV extension only. This is the highest-value one-shot scan because it verifies screen access and gives a real setup read.
Scan S2 · Pre-Session Level Map
1 prompt
Analyze MNQ first. If MNQ is unavailable, use MCL. If I later specify another instrument, use that instead. Do the following in order: 1. State yesterday's high (PDH) and yesterday's low (PDL) with exact prices. 2. State the current session high and low so far on the active instrument. 3. Is price currently above PDH, below PDL, or between them? 4. Identify the nearest untested liquidity level above and below current price. 5. What is the current 15M and 1H structure — is it making HH/HL or LH/LL? 6. Give me a one-line directional bias for this session only. Be precise. Numbers only — no vague commentary.
Use this if you want the older segmented workflow instead of the single extension scan.
Scan S3 · Timeframe Confluence Check
1 prompt
Still on the active instrument. Check 4 timeframes — 5M, 15M, 1H, 4H — and answer: 1. On 4H: update the key trendlines or trend direction context if needed. 2. On 1H: what is the main structure and bias? 3. On 15M: what is the most recent BOS direction? 4. On 5M: is there an entry-quality reaction forming right now? 5. Do all 4 timeframes align? Yes / Partial / No — and why. Keep it short. I need a trade / no-trade decision.
Use after the level map if you are not using the full extension-only scan.
Scan S4 · Setup Confirmation (Pre-Entry)
1 prompt
Price is approaching [LEVEL] on [INSTRUMENT]. I'm watching for a [LONG/SHORT] setup. Check: 1. Is this level a PDH, PDL, session high/low, or FVG — confirm which. 2. Is there any reason NOT to take this trade right now? (price already extended, weak reaction, poor structure, low quality location) 3. What is the clean stop placement and what R:R does that give at a target of [TARGET]? 4. Final call: A-grade setup / B-grade setup / Skip — and one sentence why. Do not create any alerts yet. I need to confirm first.
Use only when price is actually approaching a level and you want a focused pre-entry check.

Alert Setup Prompts

After your scan gives you the levels, use these only for non-PDH/PDL custom alerts and session guards. You already have PDH/PDL arrival alerts on your charts.

Fill in levels first. Replace bracketed placeholders with actual prices from your scan.
AlertA2 · Liquidity Level Proximity Alert
1–2 prompts
Create a price alert on [INSTRUMENT] for [LEVEL_PRICE]. This is a [describe: e.g. untested liquidity / session high / session low / trendline touch] level. Alert conditions: - Trigger: price crosses [LEVEL_PRICE] on a 15M bar close - Alert name: "XAU [short level name]" - Message: "XAU approaching [level name] at [LEVEL_PRICE] — review S2 TF alignment before entry" - Trigger once, then reset manually No webhook. Confirm alert created.
Use for secondary levels only.
AlertA3 · Daily Loss Limit Guard
1 prompt
Create a price alert on [INSTRUMENT] to act as a session kill-switch reminder. If my entry was at [ENTRY_PRICE] with a 1% risk stop, my account stop-out level is approximately [STOP_PRICE]. Set an alert at [STOP_PRICE]. - Name: "XAU DAILY LOSS LIMIT — STOP TRADING" - Message: "Price at your max daily risk level. Close all positions and close the platform." - Trigger: once, any timeframe This is a prop rule guard, not a trade alert. Confirm it is set.
Set this at the start of every live session.

Memory Prompts — Teaching Remix Your Rules

Paste the master context first each session so every later response respects your prop rules.

How to use: Copy M1 and paste it as your first message in each Remix session.
MemoryM1 · Master Context Block (Paste First Every Session)
1 prompt
Before we start: here is my trading context. Apply these rules to every response in this session. INSTRUMENTS: MNQ is primary. MCL is secondary. Other instruments may be added later and should be treated as explicitly specified only. STRATEGY: Price action only. I trade around PDH and PDL, session structure, and level reactions. TIMEFRAMES: 5M entries. 15M and 1H for checking. 4H for adjusting trendlines and broader trend context. PROP FIRM RULES (hard limits — never suggest trades that violate these): - Max risk per trade: 1% of account - Daily loss limit: $1000 — if hit, I stop trading for the day - Max drawdown: $2000 — if hit, account is at risk SESSION STATUS (fill in before pasting): - Losses today so far: [0 / 1 / 2] → If 2: flag any new setup suggestion with "REVENGE TRADE RISK — confirm you want to proceed" TRADE CRITERIA (only suggest setups that meet all of these): - Setup must be at a named level: PDH, PDL, session H/L, or identified FVG - Minimum R:R = 2:1 before I consider entry - Structure must confirm direction on 1H before entry - No revenge trading — if I have already taken two losing trades today, flag this before suggesting another PERSONALITY: Give me numbers and decisions. Only short explanations if needed.
Fill in today's loss count before pasting.
